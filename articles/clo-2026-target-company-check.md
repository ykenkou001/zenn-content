**2026年度から施行される改正物流効率化法**で、一定規模以上の荷主・倉庫・運送事業者にはCLO（物流統括管理者）の選任や中長期計画の作成が義務付けられます[^portal]。中長期計画の提出期限は、通常は「毎年度7月末日まで」ですが、**2026年度に限り経過措置として「令和8年（2026年）10月末日まで」** に延長されています。これは国交省の関係命令第6条と附則の経過措置、および業種別の対応手引書で明示されています[^command][^ninushi][^chained][^truck][^warehouse]。

この記事は、物流システム開発に携わるエンジニアが、CLO義務化対応の支援に興味を持って個人開発しているPoC「Logi-Intel Dashboard」の検討過程で整理した、**自社が対象になるかを30秒で判定するチェック**と、対象だった場合に初回提出・社内説明・提出後の運用まで何を準備するかをまとめたものです。

正確な期限・告示は、必ず下記の公式資料（ポータル本文・命令本文PDF・業種別手引書PDF）で最新情報をご確認ください。
:::

## 1. そもそも誰が対象なのか：区分の整理

改正物流効率化法では、年間の貨物量・取扱量・車両数に応じて、以下の区分が「特定事業者」として指定され、CLOや中長期計画関連の義務が課されます。閾値はすべて国交省ポータル「特定事業者の指定」ページの公式記載に基づきます[^designation]。

| 区分 | 閾値（年間） | 主な義務 |
| --- | --- | --- |
| **特定第一種荷主**（自ら貨物の運送を委託する荷主） | 取扱貨物重量 **9万トン以上** | CLO選任・中長期計画・定期報告 |
| **特定第二種荷主**（運送契約の相手方となる荷主） | 取扱貨物重量 **9万トン以上** | 中長期計画・定期報告 |
| **特定連鎖化事業者**（コンビニ・FC等の本部） | 加盟者を含めた取扱貨物重量で算定 | CLO選任・中長期計画・定期報告 |
| **特定倉庫業者** | 貨物の保管量 **70万トン以上** | 中長期計画・定期報告 |
| **特定貨物自動車運送事業者等** | 保有車両台数 **150台以上** | 中長期計画・定期報告 |

[^designation]: 国土交通省「特定事業者の指定」 https://www.revised-logistics-act-portal.mlit.go.jp/designation/

業界では、対象となる荷主・物流事業者の総数として「特定荷主 約3,200社、特定倉庫 約70社、特定運送 約790社」といった推計が報じられていますが[^cargo]、これらは業界誌の取材ベースの数字であり、国交省の公式公開資料には未記載です。自社が該当しそうな場合は、必ず国交省告示と告示対応FAQで個別の算定方法を確認してください。

[^cargo]: カーゴニュース報道 https://cargo-news.co.jp/cargo-news-main/4957

特に注意したいのは、**特定第一種荷主と特定連鎖化事業者にはCLO選任義務がある**点です[^clo]。特定第二種荷主・倉庫業者・運送事業者は中長期計画と定期報告が中心で、CLO選任の名指しは原則かかりません（ただし社内で誰が責任者かは決めておく必要があります）。

[^clo]: 国土交通省「物流統括管理者（CLO）の選任」 https://www.revised-logistics-act-portal.mlit.go.jp/clo/

そしてもう一つ重要なのが、「**自社が直接該当しなくても、取引先が対象になる可能性**」です。特定荷主に該当する荷主は、自社内の改善だけでは目標達成が難しく、取引先（運送・倉庫・連鎖化のフランチャイジー）にもデータ提出や改善協力を求めてきます。そのため、自社が9万トンに届かなくても、**主要取引先が特定荷主であれば、データ提出依頼が降ってくる**ことを想定しておく必要があります。

## 2. 30秒判定チェックリスト

判定は **2段階** で行います。最初の4項目（A）で「法的に対象となるか」を、続く4項目（B）で「対応準備が足りているか」を別々に確認してください。

Web上でそのまま判定したい場合は、Logi-Intel Dashboard の [対象判定ツール（30秒チェック）](https://d1zei8qivkf3cr.cloudfront.net/check) でも同じ8項目を確認できます。

### A. 法的該当チェック（自社が制度の直接対象か）

| 項目 | 内容 |
| --- | --- |
| A-1 | 年間の取扱貨物重量が **9万トン以上** ある（特定第一種荷主・特定第二種荷主の閾値） |
| A-2 | 自社で運営する倉庫の年間保管量が **70万トン以上** ある（特定倉庫業者の閾値） |
| A-3 | 保有車両台数が **150台以上** ある（特定貨物自動車運送事業者等の閾値） |
| A-4 | コンビニ・小売・外食・FCなど、本部から加盟店へ商品供給する **連鎖化事業** を行っており、加盟者を含めた取扱貨物重量が制度上の閾値に届く |

**Aで1個以上Yes** → 直接対象の可能性が高い区分です。国交省告示の算定方法で自社の正確な数値を確認し、特定第一種荷主・特定連鎖化事業者に該当する場合はCLO選任・中長期計画・定期報告の3点セットが必要です。

**Aで全てNo** → 制度の直接対象ではない可能性が高いですが、次のBチェックも見てください。

### B. 対応準備チェック（取引先経由の影響と社内体制）

| 項目 | 内容 |
| --- | --- |
| B-1 | 主要取引先（売上構成比上位）が、A-1〜A-3のいずれかに該当している、または該当する見込みである |
| B-2 | 物流拠点（自社倉庫・委託倉庫・配送センター）が複数県にまたがっている |
| B-3 | 取引先から「物流データの開示依頼」「中長期計画への協力依頼」を受けたことがある、または受けそうな見込みがある |
| B-4 | 物流に関する全社横断の意思決定者（役員等の経営幹部）が明確に決まっていない |

**Bで2個以上Yes** → 直接対象でなくても、取引先経由でデータ提出依頼や改善要請が降ってくる確度が高い状態です。社内体制の準備を始めておくべきです。

特に **A-4（連鎖化事業者）** がYesの場合、A-1〜A-3の閾値に届かなくても、特定連鎖化事業者として別ルートで義務（CLO選任を含む）がかかる構造になっています。コンビニ本部・チェーン外食本部・FC本部の方は注意してください。

Logi-Intel Dashboardでは、このチェック結果を入口に、対象区分・必要対応・提出までのスケジュールを確認できます。さらに自社データを入れると、業種別に見るべきKPI、優先施策、不採用にした施策の理由、中長期計画ドラフトまでつなげて確認できます。

## 3. 対象だった場合のロードマップ：2026年10月末までに何をやるか

仮に **Aで1個以上Yes**、または **Bで2個以上Yes** だった場合、**2026年度の初回中長期計画提出期限（経過措置で令和8年10月末日。実務上は2026年10月31日まで）** を見据えて、おおまかに次のステップで準備していく必要があります[^command][^ninushi]。本記事公開時点から逆算すると、計画策定・社内合意・取引先調整までを5ヶ月程度で回す前提です。

| ステップ | やること |
| --- | --- |
| **対象判定の確定** | 自社の貨物重量・取扱量・車両数を国交省告示の算定方法で確定。社内推進体制の組成、CLO候補者の検討 |
| **データ収集** | 拠点・貨物量・荷待ち時間・積載率・CO2排出量。業種別ベンチマーク把握、施策候補洗い出し |
| **中長期計画ドラフト作成** | 社内レビュー、経営会議での合意形成、取引先（運送・連鎖化加盟店）との調整 |
| **CLO選任の社内決裁** | 役員等の経営幹部から選任。所定の届出 |
| **中長期計画の提出** | 国交省ポータル公開の様式に従って、2026年10月末日（10月31日）までに提出 |
| **継続運用** | 計画に基づく施策実施、翌年度以降は毎年度7月末日が通常提出期限 |

提出に必要な「中長期的な計画」の様式と項目は、国交省ポータルで案内されています[^planning]。公式に示されている必須記載項目は次の4項目です。

[^planning]: 国土交通省「中長期的な計画の作成」 https://www.revised-logistics-act-portal.mlit.go.jp/planning/

> （ⅰ）実施する措置　（ⅱ）具体的な措置の内容・目標等　（ⅲ）実施時期等　（ⅳ）参考事項

提出頻度は **毎年度提出を基本とし、計画内容に変更がない限りは5年に一度** とされており[^planning]、通常の提出期限は命令第6条で **毎年度7月末日まで** と定められています。**2026年度の初回提出のみ、附則の経過措置で「令和8年（2026年）10月末日まで」** に読み替えられます[^command]。実務上は、上記4項目の中身として、貨物重量・荷待ち時間・荷役時間に関する数値目標、共同輸送・モーダルシフト・パレット標準化等の施策、取引先や加盟店との協力体制、投資計画とCLOを含む推進体制などを記載していくことになります。

このうち「数値目標」と「施策の優先順位」が、実務でいちばん詰まりやすい部分です。「**なぜモーダルシフトではなく、バース予約から始めるのか**」のような選外理由を社内・取引先に説明できるかが、計画の質を決めます。

Logi-Intel Dashboardでは、計画書をいきなり作るのではなく、業種別標準パッケージ、F2標準化スコア、J2罠スコア、施策評価、シナリオ試算を経由して、社内説明用PPT・提出様式ドラフト・Excel明細・HTML・Markdownの成果物に落とし込む流れを想定しています。出力物は提出用の完成版ではなく、社内レビューと最新様式確認のためのたたき台です。

なお、CLOは **「事業運営上の重要な決定に参画する管理的地位にある者」** であり、**「重要な経営判断を行う役員等の経営幹部から選任される必要」** があるとされています[^clo]。物流部長クラスだけで完結する人事ではなく、取締役会・経営会議の意思決定権を持つ人物が前提です。

## 4. 2026年11月1日以降：CLOの本当のスタートは「継続運用」

ここまで読んで「2026年10月31日に中長期計画を提出すれば、ひと区切り」と思った方は、もう一段考えておくべきポイントがあります。

中長期計画の提出は **ゴールではなく、CLO業務のスタートライン** です。命令第6条の通常規定では、**翌年度以降は毎年度7月末日まで** に定期報告を提出します[^command][^planning]。つまり、2026年10月の初回提出を終えても、2027年7月末・2028年7月末・2029年7月末と、毎年度のサイクルが続きます。

### 継続運用で求められる3つのこと

定期報告と翌年度計画見直しの場で、CLOは次の3つに継続的に答える必要があります。

| 観点 | 経営会議・国への報告で問われること |
| --- | --- |
| **実績ギャップ** | 計画した数値目標（積載率、荷待ち時間、CO2など）に対し、実績はどうだったか。乖離していた場合の原因は何か |
| **施策の選定理由** | 「なぜこの施策を採用したのか」「なぜモーダルシフトではなく、バース予約から始めたのか」「他の候補施策をなぜ外したのか」 |
| **翌年度への反映** | 未達KPIをどう取り戻すか、施策の追加・撤回・優先順位の入れ替えをどう判断するか |

特に2つ目の「**施策の選定理由**」は、社内合意・取引先説明・関係省庁への報告のいずれの場面でも繰り返し問われます。「やった施策」を語るだけでは足りず、「**やらなかった施策の理由**」まで説明できる状態にしておく必要があります。

### 意思決定証跡を残す体制が必要になる

ここで効いてくるのが、CLOが日々下している判断を **意思決定証跡（decision log）** として残す体制です。

- いつ・誰が・何を根拠に・どの施策を採用／不採用にしたか
- そのときの前提条件（燃料価格、需要見通し、社内体制）は何だったか
- 実績が乖離したとき、前提のどこが外れたのか

これらは初回計画作成時には軽視されがちですが、**翌年度の定期報告と経営会議で必ず参照されます**。中長期計画書のドラフト作成と同じくらい、意思決定証跡を継続的に残せる仕組みが、CLO体制の中核になります。

つまり、2026年10月末までに準備すべきは「**初回提出物**」だけでなく、「**翌年度以降も毎年7月末に同じ品質で報告を出し続けられる継続運用の型**」です。

## 5. 業種別に気をつけるポイント

業種によって、施策の組みやすさと制度上の制約が違います。

**食品・飲料**:
- 最初に見るKPI: 多温度帯車両の積載率、納品時間ピークの分散度
- 最初に揉める論点: 賞味期限・小口頻度配送が前提のため共同輸送が組みにくい中で、納品リードタイムの延長と冷温混載の品質保証をどこまで取引先に飲ませるか

**化学・素材**:
- 最初に見るKPI: 輸送モード別の輸送量シェアとCO2原単位、危険物車両の専用稼働率
- 最初に揉める論点: モーダルシフト（鉄道・内航海運）に切り替えた際の納期遅延リスクと輸送品質保証を、社内の生産・営業部門に納得させられるか

**小売・アパレル**:
- 最初に見るKPI: 店舗当たりの納品回数、1便あたりの積載率、センター在庫日数
- 最初に揉める論点: 「毎日納品」を前提とした店舗オペレーションを維持するか、納品頻度削減・店舗発注ロット標準化に踏み込むか

**連鎖化事業者（コンビニ・外食FC等）**:
- 最初に見るKPI: 配送センターの稼働率、加盟店当たりの配送回数と1回あたり荷量
- 最初に揉める論点: 本部主導の改善施策（共同配送、納品時間統一など）と、加盟店との契約・FCマニュアル上の根拠の整合。一律的な負担増を加盟店に強いる施策は **制度上の論点** になりやすい区分のため、本部主導と契約整合の両立が必須

実務でよく問われる「自社の業種で、何の施策から手をつけるべきか」については、経済産業省の **CLO取組事例集** に先行各社（SUBARU・J-オイルミルズ・日清食品・日本アクセス・サンゲツなど）の取り組みがまとまっています。業種が近い企業の事例を最初に押さえると、社内提案の説得力が変わります[^cases]。

[^cases]: 経済産業省「CLO取組事例集 - 物流改革の実践と成果」 https://www.meti.go.jp/policy/economy/distribution/CLO_collection_of_cases.pdf

## 6. 罰則と実害：払えるかではなく、信用リスクの方が重い

CLOに関する罰則は、国交省ポータルで以下のように明示されています[^clo]。

- **CLOを選任しない場合**: 百万円以下の罰金
- **CLO選任の届出を怠った場合**: 20万円以下の過料

加えて、中長期計画の作成や定期報告に関する義務違反についても、法令上の罰則・命令対象となる可能性があります（詳細は国交省ポータルおよび関連告示で確認してください）。

ただし、上場企業・大手取引先を持つ企業にとっての本当のインパクトは、罰金額そのものではなく、**取引先説明と社内決裁が重くなること** の方です。具体的には次のような場面が想定されます。

- **取引先のサプライヤー査定**: 特定荷主企業の購買・物流部門が、取引継続条件として「中長期計画提出済み」「CLO選任済み」を求める動きが出始めています。さらに2027年度以降は、**「定期報告が継続して回っているか」「計画値と実績値の乖離をどう説明しているか」** といった継続運用の品質も問われ始める想定です。未対応のままだと、新規取引・契約更新の場で説明責任が発生します
- **IR・統合報告書**: 上場企業の場合、法令対応状況をCSR報告書や統合報告書、株主総会想定問答で問われる可能性があります。「罰金額そのもの」より、未対応であることをどう開示するかの方が重い論点になります
- **金融機関・投資家**: サステナビリティ評価項目（CO2排出、サプライチェーン労務環境）に、物流効率化法対応が組み込まれる流れの中で、未対応が融資条件・ESG格付に響く可能性があります
- **業界団体での共有会**: JILS等の業界団体で進捗状況が共有される場で、未対応企業として目立つことのレピュテーション影響[^jils]

[^jils]: JILS（日本ロジスティクスシステム協会）報道リリース https://www1.logistics.or.jp/news/news-2322/

「100万円なら払える」という発想ではなく、**法令対応が信用情報・取引条件の一部になりつつある**という前提で考えた方が、社内の優先順位は正確になります。
